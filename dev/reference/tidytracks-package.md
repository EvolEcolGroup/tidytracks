# tidytracks: Functions to Analyse Tracking Data

A grammar for animal tracking data analysis based on 'move2' objects.
The package provides a consistent and expressive set of tools for
manipulating tracks and associated metadata, allowing common
movement-ecology workflows to be combined into clear and reproducible
analyses. Functionality includes location filtering, trip segmentation,
summary statistics, home range estimation and visualisation. Built on
the 'sf' spatial framework, it integrates naturally with the tidyverse
ecosystem.

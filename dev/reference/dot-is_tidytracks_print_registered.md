# Check whether tidytracks printing is currently registered

Check whether tidytracks printing is currently registered

## Usage

``` r
.is_tt_print_registered()
```

## Value

`TRUE` if
[`print_move2_tt()`](https://evolecolgroup.github.io/tidytracks/dev/reference/print_move2_tt.md)
is currently registered for `print.move2`; otherwise `FALSE`.
